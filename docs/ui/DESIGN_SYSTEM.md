# Design System

이 문서는 DDUK ERP 디자인 시스템 문서 슬롯이다.

현재 확정 기준은 `frontend/dashboard.html`과 `frontend/styles/common/dashboard.css`에 있는 카드, 버튼, 테이블, 사이드바, topbar 스타일이다.

---

## 작성 상태

- 상태: 초안
- 분류: `ui`
- 범위: 색상, typography, spacing, 카드, 버튼, 테이블, 상태 배지

---

## 작성 기준

- 카드형 UI는 기존 dashboard 톤을 따른다.
- 버튼, 테이블, 통계 카드는 공통 스타일을 우선한다.
- 라운드, 그림자, border는 화면마다 새로 만들기보다 공통 기준을 따른다.
- 화면별 CSS는 중복을 최소화한다.
