# UI Guide

이 문서는 DDUK ERP 화면 작성 기준 문서다.

현재 UI 기준은 `frontend/dashboard.html`과 공통 스타일을 기준으로 한다.  
상세 화면별 확정 UI 문서는 아직 분리되어 있지 않으므로, 이 문서는 UI 문서 슬롯과 작성 기준을 정의한다.

---

## 작성 상태

- 상태: 초안
- 분류: `ui`
- 범위: 화면 구조, 공통 컴포넌트 사용 기준, 반응형 기준

---

## 작성 기준

- UI 문서는 화면 구조와 디자인 시스템만 포함한다.
- API 규격, 에러 처리, 아키텍처는 `docs/common/`에 둔다.
- Bootstrap은 사용하지 않는다.
- 기존 dashboard 스타일을 우선 재사용한다.
