# Dashboard Layout

이 문서는 DDUK ERP 대시보드 레이아웃 문서 슬롯이다.

현재 확정 기준은 `frontend/dashboard.html`의 sidebar, topbar, content area, KPI grid, section card 구조다.

---

## 작성 상태

- 상태: 초안
- 분류: `ui`
- 범위: sidebar, topbar, content area, KPI grid, section card, responsive layout

---

## 작성 기준

- 첫 화면은 실제 업무 화면을 우선한다.
- KPI 카드는 카드형 UI로 구성한다.
- 주요 데이터 테이블은 가로 스크롤과 Empty State를 고려한다.
- 반응형 breakpoint는 `1024px`, `768px`, `576px`를 우선 사용한다.
